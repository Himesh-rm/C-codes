## ⭐ Featured Mini Project — Billing System

📍 **Path:** [`College-Codes/Mini_Project.cpp`](College-Codes/Mini_Project.cpp)

A **console-based retail invoice generator** producing clean, receipt-style bills.

| Feature | Description |
|:--------|:------------|
| 🧾 **Dynamic Items** | Accepts any number of items with name, quantity & price |
| 💰 **GST Calculation** | Auto-computes 18% tax per item + grand total |
| 📐 **Formatted Output** | Aligned columns using `<iomanip>` — `fixed`, `setprecision` |
| 🕒 **Auto Timestamp** | Invoice date & time via `__DATE__` / `__TIME__` macros |
| 🏪 **Invoice Banners** | Professional header & footer layout |

```bash
g++ "College-Codes/Mini_Project.cpp" -o billing && ./billing
```
